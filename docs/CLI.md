# CLI

Commands: init, doctor, run, report, map, generate-test, coverage, mcp. Use COMMAND --help for exact flags. Exit0: success;1: executed journey assertion failure;2: input/environment/tool error. Use an installed absolute Node entry or node dist/cli.js from a built source tree.

Run --flow FILE --base-url ORIGIN --json against an authorized synthetic target. Saved report --run ID rebuilds HTML; map --compare HEALTHY_ID BROKEN_ID --json builds observed divergence. generate-test --run VERIFIED_SOURCE_ID --dry-run --json previews grounded code; writing/execution is explicit. coverage uses selected declared-step denominators, not whole-app coverage. Use actual IDs printed by the packaged demo, from its actual workspace.
