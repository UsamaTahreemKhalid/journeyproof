# Error catalog and recovery

Exit codes remain 0 successful command, 1 executed journey failed, 2 input/environment error. A deliberately broken regression test is a real failure; only the separate diagnostic harness expects its runner exit 1. Machine-readable commands retain JSON output. Use `COMMAND --help` for focused instructions.

| Symptom                                   | Recovery                                                                                                                                                                                          |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unsupported Node / engine warning         | Use Node >=24.11 <25. Do not infer support for another major from successful dependency installation.                                                                                             |
| Missing Chromium / OS libraries           | Run the matching installed `playwright/cli.js install chromium`; on Linux use --with-deps if permitted. Doctor launches/checks but never installs.                                                |
| Wrong workspace                           | Set JOURNEYPROOF_WORKSPACE_ROOT to an existing absolute application directory before MCP/generation; tool arguments cannot change it.                                                             |
| Flow path denied                          | Set approved JOURNEYPROOF_FLOW_ROOT at startup and use paths beneath it. No traversal/absolute flow paths through MCP/generation.                                                                 |
| Invalid YAML / unsupported action         | Check schemaVersion 1, seven supported actions, unique IDs, locator shape and explicit outcome. Diagnostics omit unknown attacker-controlled fields.                                              |
| Missing environment input                 | Supply the named binding externally; never paste values into tool arguments, generated code or issue reports.                                                                                     |
| Report/map absent or corrupted            | Use a printed ID and original artifact root. Do not edit JSON to turn failure green. Re-run the synthetic fixture if evidence was removed.                                                        |
| Generation ineligible                     | A passed linked run, matching current YAML, complete observations, HTTP proof and final explicit outcome are required. Definition-only is unexecuted; drafts are non-executable.                  |
| Modified output exists                    | Review changes. CLI --force is explicit; MCP never force-overwrites. A dry-run creates no files.                                                                                                  |
| MCP silence/no tools                      | Silence before a client connects is normal. Use node with the absolute installed dist/cli.js path and mcp argument, not npm run. Verify workspace and client stderr privately.                    |
| Disallowed URL                            | MCP/generated tests accept numeric loopback only; remote, metadata and localhost DNS targets remain blocked. Historical CLI --allow-remote is separate explicit authorization, not a fix for MCP. |
| ERR_MODULE_NOT_FOUND after install        | Reinstall the audited tarball/dependencies. CLI must work without checkout dev dependencies; generated tests separately require matching @playwright/test.                                        |
| Generated spec not selected               | Use examples/ci/regression.config.mjs with its explicit workspace/spec environment or configure your own testDir. Old checkout config selects tests/e2e.                                          |
| Windows shim/import problem               | Use node.exe with the explicit installed JS path. ESM absolute imports require file URLs. Native browser/--open behavior is not claimed tested.                                                   |
| Package check script used directly        | Use npm run test:package so npm_execpath points to npm's JS entry; direct node invocation of the internal development harness is not its supported interface.                                     |
| Dependency/browser install needs internet | Installation/audit may contact npm and Playwright download services. Runtime offline reports are a different claim.                                                                               |

Known limits: synthetic disposable accounts only; no general PII detector, DNS firewall or hard-kill cleanup guarantee. One page, bounded evidence and existing timeouts remain. No auto-update, telemetry, arbitrary page script tool or external AI service. Native screenshot/trace artifacts must still be reviewed before sharing. [Security model](SECURITY.md), [generation limits](REGRESSION_GENERATION.md), [support](../SUPPORT.md).

For the frozen local candidate use [verified setup](INSTALLATION.md). Keep the first failed command/exit code, safe run ID and exact package SHA-256; do not retry repeatedly to disguise a failure. Fixture readiness failures require checking the local process/browser prerequisites, not a production URL substitution.
