## Reporting a Security Vulnerability

Security vulnerabilities in JourneyProof should be reported privately.

### How to report

Email: usamatahreem@hotmail.com

Please do not disclose security vulnerabilities through public GitHub Issues, pull requests, or discussions.

When reporting a vulnerability, please include:

- A clear description of the issue
- The affected JourneyProof version
- Steps to reproduce the problem
- Potential security impact
- A minimal, non-destructive proof of concept, if available
- Any recommended mitigation

Please avoid including actual credentials, personal information, or sensitive application data.

### What to expect

JourneyProof is an independently maintained open-source project.

Security reports will be reviewed on a best-effort basis. We cannot guarantee response or resolution times.

We appreciate responsible disclosure and encourage reporters to allow time for investigation and remediation before publicly disclosing a vulnerability.

### GitHub Private Vulnerability Reporting

Once the repository is public and GitHub Private Vulnerability Reporting has been enabled, security researchers may also use the repository's private vulnerability reporting feature.

Until that feature is verified as enabled, use the security email above.
