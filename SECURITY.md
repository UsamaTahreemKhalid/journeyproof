# Security

No stable public release or security response SLA exists. Current scope is the private `0.1.0-rc.1` candidate and recorded local tests. Report vulnerabilities privately through the channel used to obtain this candidate until the owner configures a verified reporting route. Do not disclose exploit details or raw sessions in public issues.

Maintainers may investigate/fix at their discretion without deadlines. Use synthetic authorized targets, minimize evidence and review images/traces before sharing. [Threat model](docs/SECURITY.md). Source licensing is Apache-2.0; third-party rights review and release authorization remain separate owner decisions.

Before public visibility, the owner must configure and verify a confidential reporting route that new users can access. Do not assume GitHub private vulnerability reporting is enabled. This root policy describes reporting and response expectations; [docs/SECURITY.md](docs/SECURITY.md) describes implementation boundaries and limitations.
