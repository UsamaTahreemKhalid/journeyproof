# Contributing

Source licensing is Apache-2.0; see [LICENSE](LICENSE) and [NOTICE](NOTICE). External contributions remain closed pending owner approval of contribution rights and reporting policy. No CLA/DCO or contributor grant is imposed by this candidate. Invited maintainers should use Node24.11+ within24, npm ci, explicit Chromium installation and npm run ci.

Preserve strict TypeScript, all tests/coverage thresholds, typed schemas, the shared engine and truthful assertion/evidence semantics. Add regression tests for real defects, use synthetic fixtures and document limitations. Keep secrets/artifacts out of Git. No publication/visibility/license changes without separate approval. [Support](SUPPORT.md), [security](SECURITY.md).
