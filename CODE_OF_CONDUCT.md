# Private collaboration conduct — draft

JourneyProof is private and external contributions are not open. This draft is for owner review, not an adopted public community policy. Invited collaborators should be respectful, factual and inclusive, avoid harassment and disclosure of private information, and discuss technical disagreements without personal attacks. Use synthetic examples and minimize collected evidence.

Report concerns privately through the existing owner channel; no public email, enforcement team or response-time guarantee is invented. The owner decides handling and any future public policy. Do not create a public issue containing personal or sensitive information. [Contribution status](CONTRIBUTING.md) · [private security reporting](SECURITY.md).
