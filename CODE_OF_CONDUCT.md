# Collaboration conduct

Participants should be respectful, factual and inclusive, avoid harassment and disclosure of private information, and discuss technical disagreements without personal attacks. Use synthetic examples and minimize collected evidence. External contributions remain closed pending owner approval; see [Contributing](CONTRIBUTING.md).

Do not create a public issue containing personal or sensitive information. Report vulnerabilities privately using [SECURITY.md](SECURITY.md). The maintainer handles concerns at their discretion without a guaranteed response time.
